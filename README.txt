КАК ЗАГРУЗИТЬ:
1) Откройте github.com/rinat2026-15/motopompy-dchs-sko
2) Add file → Upload files.
3) Перенесите содержимое ЭТОГО АРХИВА (кроме README.txt по желанию) в КОРЕНЬ репозитория.
4) Commit changes. Не удаляйте репозиторий, не запускайте SQL повторно.
5) Откройте https://rinat2026-15.github.io/motopompy-dchs-sko/?v=40
6) Должно быть написано: «Версия 4.0 · проверена в браузере».
7) Нажмите «Администратор», введите свой email и пароль Supabase Auth.

Если появляется «Этот пользователь не назначен администратором»: в Supabase,
Table Editor → mp_admins → Insert row, вставьте User UID из Authentication → Users
в поле user_id. Пароль и service_role никому не передавайте.

Файлы приложения: index.html, config.js, manifest.webmanifest,
service-worker.js, icons/icon-192.png, icons/icon-512.png.
Таблицы optp_* и схема Supabase не изменяются при загрузке этих файлов.
