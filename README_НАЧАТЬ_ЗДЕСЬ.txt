УЧЁТ МОТОПОМП ДЧС СКО — ОДНА ССЫЛКА (PWA v3)

Что есть:
- Одна ссылка GitHub Pages для Android, iPhone и ПК.
- Общая таблица Supabase: подразделения, переносные/прицепные модели, количество, исправные/неисправные/ремонт, комплектация.
- 5 общих фото для каждой модели (Supabase Storage).
- Чтение без входа; запись только у пользователей, внесённых в app_admins.
- Сохранение резервной копии JSON (для резервирования/переноса данных из v1/v2).

ШАГ 1 — Supabase
1. Создайте ОТДЕЛЬНЫЙ Supabase проект (или используйте существующий при осознанном выборе и наличии доступа к SQL).
2. SQL Editor -> выполните файл supabase_setup.sql. ВНИМАНИЕ: скрипт создаёт общие таблицы public.app_admins и public.pump_state. Если app_admins уже существует, изучите существующую структуру и политики перед запуском.
3. Authentication -> Users -> Add user: создайте администратора с Email/Password.
4. Скопируйте UUID созданного пользователя и выполните отдельным SQL-запросом:
   insert into public.app_admins(user_id) values ('ВСТАВИТЬ-UUID') on conflict do nothing;
5. Settings / API (или Connect): скопируйте Project URL и ключ public publishable/anon.
   Важно: НИКОГДА не вставляйте service_role или secret key в config.js!

ШАГ 2 — config.js
Откройте config.js и замените https://YOUR-PROJECT.supabase.co и sb_publishable_REPLACE_ME на ваши значения.

ШАГ 3 — GitHub Pages
1. Создайте публичный репозиторий motopompy-dchs-sko на GitHub.
2. Загрузите в корень репозитория index.html, config.js, manifest.webmanifest, service-worker.js и папку icons.
3. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
4. После публикации ссылка будет примерно https://rinat2026-15.github.io/motopompy-dchs-sko/ (только если репозиторий создан в аккаунте rinat2026-15).
5. Откройте ссылку в Safari на iPhone -> Поделиться -> На экран Домой. На Android -> Chrome -> Добавить на главный экран / Установить приложение.

ШАГ 4 — проверить
- Откройте ссылку на двух телефонах.
- Администратор -> Email/Password -> войти -> добавить подразделение, затем модель и фото.
- На втором телефоне нажмите Обновить: данные должны появиться.

ВАЖНО:
- Пока сервер не настроен и файлы не опубликованы, публичная ссылка НЕ РАБОТАЕТ. Ссылку заранее не создавали.
- Данные и фото доступны любому, у кого есть ссылка: не размещайте персональные или ограниченные служебные сведения.
- Приложение работает с сетью; без интернета свежие данные не загружаются.
- Структура: одна JSON-запись. Не рекомендуется одновременно редактировать с нескольких админ-устройств — последнее сохранение перезапишет предыдущие изменения.
- Не использовать старый локальный пароль v1/v2: здесь серверная проверка прав.
- Для переноса старых данных сначала в v1/v2 экспортируйте резервную копию; в новой версии импортируйте JSON после входа администратора.
